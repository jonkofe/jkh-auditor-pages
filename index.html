Jkh Auditor

Персональная система анализа расходов на жилищно-коммунальные услуги.

О приложении

Jkh Auditor — частное некоммерческое приложение для автоматизированного получения и анализа электронных квитанций ЖКХ.

Приложение помогает сравнивать ежемесячные начисления, тарифы, потребление коммунальных ресурсов и перерасчёты.

Интеграция с Gmail

Для поиска электронных платёжных документов приложение использует Google Gmail API с разрешением gmail.readonly.

Доступ используется для чтения сообщений, относящихся к получению квитанций ЖКХ. Приложение не отправляет, не изменяет и не удаляет письма.

Обработка данных

Полученные PDF-документы и результаты их анализа обрабатываются и хранятся на частном сервере владельца приложения.

Данные не размещаются на этом публичном сайте. Платёжные операции приложение не выполняет.
