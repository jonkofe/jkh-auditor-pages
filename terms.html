Условия использования

Приложение: Jkh Auditor

Дата обновления: 11 ноября 2026 года

1. Назначение приложения

Jkh Auditor — личное некоммерческое приложение для автоматизированного получения и анализа электронных квитанций жилищно-коммунальных услуг.

Приложение предназначено для сравнения начислений, тарифов, показаний счётчиков и перерасчётов за разные периоды.

2. Доступ к Google Gmail

Для поиска и получения электронных квитанций приложение использует Google Gmail API с разрешением gmail.readonly.

Доступ предоставляется владельцем Google-аккаунта добровольно через OAuth 2.0. Приложение не отправляет, не изменяет и не удаляет электронные письма.

3. Обработка документов

Полученные квитанции и результаты их анализа сохраняются на частном сервере владельца. Публичный сайт используется исключительно для размещения информации о приложении.

4. Ограничения

Результаты анализа носят информационный характер. Приложение не является официальным сервисом поставщика коммунальных услуг и не гарантирует обнаружение всех ошибок в начислениях.

Jkh Auditor не осуществляет оплату квитанций и не изменяет данные в системах поставщиков услуг.

5. Доступность

Приложение предоставляется для личного использования без гарантии непрерывной доступности и без коммерческой поддержки.

6. Прекращение использования

Владелец аккаунта может в любой момент отозвать доступ приложения к Gmail в настройках безопасности Google.

Отзыв доступа прекращает дальнейшее получение почтовых данных, но не удаляет автоматически уже сохранённые документы.

7. Конфиденциальность

Порядок обработки и хранения данных описан в Политике конфиденциальности.
